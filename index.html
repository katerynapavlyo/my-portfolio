Про мене

Я веб-розробниця, яка спеціалізується на верстці та створенні зручних користувацьких інтерфейсів. Захоплююся сучасними технологіями, чистотою коду та деталями в UX/UI дизайні.

Стек технологій та інструменти:

  • HTML5 / CSS3
  • JavaScript / TypeScript
  • Git / GitHub
  • VS Code
  • Python / C++

Мої переваги:

  • Пунктуальність та дотримання дедлайнів.
  • Адаптивна верстка під усі типи пристроїв (ПК, планшети, смартфони).
  • Уважність до деталей та побажань замовника.
